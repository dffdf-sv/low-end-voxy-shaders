# Low-End Voxy Shaders

An original, performance-first Minecraft shaderpack focused on low-end GPUs and Voxy compatibility.

## Goals

- Low-end preset enabled by default
- Lightweight lighting and shadows
- Subtle bloom and colour grading
- Lightweight water and sky improvements
- Avoids ray tracing, heavy volumetrics, depth of field and motion blur
- Designed to coexist with Voxy distant terrain rendering
- Conservative GLSL for broad Iris/OptiFine-style compatibility

## Important compatibility note

No single shaderpack can guarantee compatibility with every Minecraft, Iris, OptiFine and Voxy release because shader interfaces change between versions. This project deliberately avoids version-specific features where practical and will maintain version-specific fixes when needed.

## Licensing

The shader implementation is original and does not copy shader source from third-party shaderpacks. Popular shaderpacks may inspire broad visual goals, but their source code and assets remain under their own licenses.
